# OH! Civics

Interactive Ohio civic-education website focused on political literacy and civic engagement for young voters.

## Current game structure

### Health — The Committee Room
One standing-committee game with five connected scenes:

**briefing → testimony → amendment markup → member discussion → committee vote**

Persistent indicators: **Committee Support** and **Bill Clarity**.

### Culture — The Drafting Desk
One bill-drafting game with five connected scenes:

**case file → community voices → clause puzzle → sponsor markup → final printed draft**

Persistent indicators: **Draft Clarity** and **Sponsor Support**.

The Judiciary module remains removed. The Ohio district explorer and source pages remain part of the website.

## Running locally

Open `index.html` in a browser.
